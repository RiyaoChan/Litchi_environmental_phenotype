# 荔枝气象—物候—产量数据

本仓库汇总了用于探索荔枝气象、物候与产量关系的原始资料。

## 数据内容

- `物候期.xlsx`：物候期数据
- `测产.xlsx`：测产/产量数据
- `气象数据原/`：海口市、陵水县 2021—2026 年气象数据
- `示范园/`：2021—2026 年荔枝龙眼产业技术体系示范园资料
- 根目录中的 2026 年示范园资料

原始正式文件保持原样上传；Microsoft Office 自动产生的 `~$` 临时锁文件未纳入版本控制。

## 拟研究问题

围绕“气象—表型（物候）—产量”关系，评估现有数据更适合开展：

1. 气象因子对关键物候期和产量形成的影响分析；
2. 根据气象数据预测物候期或产量；
3. 根据物候观测反演关键环境条件；
4. 气象通过物候影响产量的路径/机制分析。

后续建模前需进一步核对各数据表的字段定义、时间尺度、地点、品种、样本量、缺失值及不同文件之间可用于关联的键。

```bash

python -m pytest -q -ra
```
