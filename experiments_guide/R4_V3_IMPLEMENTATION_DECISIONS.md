# V3预运行实现约定（在任何V3外层预测结果生成前锁定）

1. 本轮基于c0c019061623f16af0fc9f786540ef410cd0750b；原始数据、R2/R3输出不覆盖。所有新建模数据采用R4，区域代理只在主实验完成后做一次日尺度敏感性。
2. 物候时间只精确到日。日累计包括起始日和事件日；小时累计从起始日00:00至事件日23:00，用越过训练阈值的小时所属日期评价。不推断观测日内的精确发生时刻。阶段共同边界日会在相邻描述窗口重复，已明确约定。
3. 所有候选和下游特征写入五个r4配置。非线性H3固定低端5℃、仅比较6个三角形候选（顶点12/15℃，上端20/22/25℃）。这是有限有界工作模型，不是估计出荔枝真实生理三基点。低温诱导方向参考Menzel与Simpson控制温度实验；该论文不直接验证本研究候选形状：[1995原始研究摘要](https://era.dpi.qld.gov.au/id/eprint/13008/)。
4. 每个训练划分内：按整年内层验证选择温度参数，按同果园训练事件累计量中位数估计阈值；没有同果园训练样本时回退训练总体中位数。候选并列取配置中最前项，不能按测试误差打破并列。阈值为0/非有限视不可预测。
5. 截止日期统一为收获年6月30日，不用留出样本真实终点裁剪预测搜索区间。未达阈值输出NA和未达状态；在模型比较中保留该样本并用预注册365天惩罚，不以删除失败样本提高分数；另报成功预测数及条件误差。
6. 外层LOYO允许未来年份进入训练，因此只称回顾验证。rolling-origin仅用更早年训练。各模型同一任务使用完全相同测试样本。只有5年，按年自助重采样区间仅作描述性不确定性，不冒充独立外部验证。
7. W3是逐步链式预测：已观测秋梢→预测抽穗→预测盛花→预测成熟。P2/P3单阶段验证可使用已观测起点，但W3绝不读取测试季后续真实事件。模型家族也在当前训练划分内部选择，不能把全体LOYO最佳家族反灌到外层折。
8. 产量外层训练样本的W3必须在该外层训练集内再次按年交叉拟合；内层Ridge调参要重新生成其训练/验证窗口。不能复用“全数据一次LOYO”的训练特征，因为那会间接携带外层测试年的物候。W1-M中位边界同样仅来自相应训练划分。
9. 六个主连续特征上限对PHENO扩展仍生效：该扩展使用预注册四个天气指标+两项预测日期，不在六个天气指标上再叠加两个。所有Ridge缩放和alpha选择仅用对应训练划分。
10. 固定GDD=10℃只用于各类窗口的统一描述性参考，不是声称模型最优Tb。P1诱导指标由对应训练划分的日尺度模型选择，在四种窗口间保持同一指标定义，避免把窗口差异和特征算法差异混淆。
11. 正常产量主对比只比较四类窗口均可生成特征的共同样本；不把缺日期或未达阈值样本默默扔掉，须披露并重新判断样本闸门。红明2026无定量物候，恢复敏感性可报告Y-B0/W1C，但不能伪造W2起止日期。
12. 全部天气来自事后再分析。W3消除的是“未来真实物候”泄漏，不代表拥有预测发行日当时的未来天气预报；任何产量结论仍是给定已实现天气的条件预测形式，不能直接称实时业务预报。
13. 扩展只在对应主温度模型先优于历史基线后运行；无增益不追分。情景固定训练模型，温度平移不修改非温度字段；不借重拟合制造情景效应。基础模型不稳定就不输出正式情景影响数字。
